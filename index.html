> file-to-md --watch

drop files, get .md

.txt, code files, .docx, .pptx, and .pdf go in — clean markdown files come out, saved straight to your downloads.

⇩
drag files here, or click to browse
multiple files at once is fine
how it works: everything happens locally in your browser — nothing is uploaded anywhere. text/code files are wrapped as-is (code gets a fenced block). .docx is converted to real markdown formatting. .pptx pulls out each slide's title, bullet points, and any pictures (embedded directly in the markdown). .pdf has its text extracted (layout/formatting is lost, pdfs are messy that way). each file downloads with the same name and a .md extension.
